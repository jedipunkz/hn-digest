タイトル: AI がプロジェクトを理解するための VSCode 拡張機能
HN テキスト: ワンクリックでスキルをインストールできる VSCode プラグインを書きました。コードを書くとAIが自動で詳しいコメントを書いてくれます。プラグインはそれらを認識して JSON に変換できます。 AI が何かを理解したい場合、インターフェイスを自動的に呼び出して、メソッド チェーン全体と対応するコメントの導入を取得できます。 main 関数の読み取りには数秒しかかかりません。見栄えを良くするために、表示するための HTML も作成しました。もちろん、それは見た目のためだけです。このプラグインはオープンソースであり、DevMap の VSCode プラグイン マーケットにアップロードされています。実用性は平均的かもしれませんが、見た目は魅力的です。

## Original Extract

I wrote a VSCode plugin that can install skills with just one click. When writing code, AI automatically writes detailed comments. The plugin can recognize and convert them into JSON. If AI wants to understand something, it can automatically call the interface to obtain the entire method chain and corresponding comment introduction. Reading a main function only takes a few seconds. To make it look better, I also created an HTML to display it. Of course, it's just for the sake of appearance. The plugin is open source and has been uploaded to the VSCode plugin market on DevMap. Although its practicality might be average, it is visually appealing.
