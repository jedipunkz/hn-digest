rtk - dev-command 出力を圧縮する CLI プロキシ (縮小のみの見出し) - rtk は、一般的な dev コマンドの出力が LLM コーディング エージェントのコンテキスト ウィンドウに到達する前にインターセプトして圧縮する、シングルバイナリの Rust CLI プロキシです。

Anthropic のベンダー ネイティブ コンテキスト管理 (コンテキスト編集 + メモリ ツール + サーバー側コンパクション) - Anthropic のコンテキスト編集、メモリ ツール、サーバー側コンパクションにより、ベンダーの報告によると、100 ターンの Web 検索評価でトークン消費量が 84% 削減されました。

コンテキストの腐敗 - 入力の長さが増加するにつれて LLM のパフォーマンスが低下します - これは、LLM の出力品質が入力としてどのように変化するかに関する Chroma の制御された研究です

長さは増加しますが、タスクの難易度は固定されています。
ContextBudget - 予算に制約された逐次決定としてのコンテキスト管理 - ContextBudget の BACM メソッドでは、固定ルールではなく、残りのコンテキスト バジェットに基づいて、エージェントがいつ、どの程度履歴を圧縮するかを決定します。
カーソル ベンダー ネイティブのコンテキスト管理 - 動的なコンテキスト ディスカバリ + Composer の自己要約 - カーソルの動的なコンテキスト ディスカバリは、熱心にではなくオンデマンドでツール スキーマと大規模な出力をロードします。この変更により、コンテキストの使用量が 46.9% 削減されたとベンダは報告しています。
Repomix - リポジトリ全体を単一の AI 対応ファイルにパックし、トークン数を報告し、Tree-sitter を使用してコードを署名のみに圧縮します。

自己圧縮言語モデル エージェント - この文書では SELFCOMPACT を紹介します。固定間隔の要約の代わりに、増大するエージェント トレースをいつどのように圧縮するかをモデル自体が決定します。
