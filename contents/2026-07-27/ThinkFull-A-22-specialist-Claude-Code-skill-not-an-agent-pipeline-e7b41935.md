クロード・コードのための学際的な思考スタジオ。
22人の世界クラスのスペシャリスト。スキルファイルは1つ。あらゆる課題、あらゆる領域。
supernotesonline.github.io/ThinkFull
ThinkFull は、課題について説明した瞬間に専門家チーム全体をアクティブにするクロード コード スキルです。 /thinkfull と入力するたびに、適切なスペシャリストがあなたの課題に対してアクティブになります。戦略、デザイン、エンジニアリング、成長、ブランド。プロジェクトに必要な規律を 1 つのマークダウン ファイル内に収めます。
エージェントはいません。パイプラインはありません。オーケストレーションのオーバーヘッドはありません。クロードのセットアップにスキル ファイルをドロップするだけです。
mkdir -p ~ /.claude/skills/thinkfull &&curl -fsSL https://raw.githubusercontent.com/SuperNotesOnline/ThinkFull/main/skill/SKILL.md -o ~ /.claude/skills/thinkfull/SKILL.md
2. クロードコードを再起動します。
/考える
それだけです。デジタル プロジェクトのあらゆる課題をクロードに投げかけると、22 人のスペシャリスト全員が舞台裏で協力します。
