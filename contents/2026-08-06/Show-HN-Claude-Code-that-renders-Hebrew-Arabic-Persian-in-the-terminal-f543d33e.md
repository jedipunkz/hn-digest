デスクトップ ショートカット上のフォルダー ピッカー ダイアログ (上のスクリーンショット) - フォルダー ツリーを参照するか、Windows パスと inl を入力/貼り付けます。

ラジオ ボタン モデルの選択 (Opus / Sonnet / Haiku)、ワンクリック フラグ チップ (ヘブライ語で応答、手間がかかる、ファイル編集の自動受け入れ、読み取り専用など)、および /voicemode:converse のような起動スラッシュ コマンド用のテキストエリアがあります。
ファイル エクスプローラーの任意のフォルダーで [Kivun ターミナルで開く] を右クリックすると、ピッカーをスキップして、そのフォルダーが直接起動します。
すべての Claude Code セッションの下部にある 2 行のライブ ステータスライン - モデル、コンテキスト %、合計トークン、セッション期間、リセットまでのカウントダウン付きの 5 時間/7 日間の使用状況。
Konsole のターミナルの背景色を、フォルダー ピッカーの詳細オプションで (または構成内の TERMINAL_COLOR= 経由で) 選択します。水色の Kivun ( #C8E6FF ) がデフォルトでオンになっています。 dark 、 black 、white 、default (エミュレータ独自のテーマ)、または #1e1e2e のようなカスタム 16 進数に切り替えます。読みやすくするために、テキストの色が自動的に選択されます。 [今すぐ適用] を選択すると、新しいタブ (Ctrl+Shift+T) に色の変更がすぐに表示されます。それ以外の場合は、次回の起動時に適用されます。
フォルダー ピッカーの詳細オプションから WSL のメモリを制限します。WSL2 は、大量の RAM を保持できる小さな Linux VM を実行します。制限を設定します ( .wslconfig に保存されます)。これは、WSL が次回再起動された後に有効になります。
Claude Code の TUI におけるヘブライ語/アラビア語/ペルシア語のレンダリングのバグを修正する BiDi ラッパー (7 つの具体的な修正については、以下の BiDi ラッパーを参照してください)。
WSL2 + Ubuntu + Konsole + Node.js + Claude Code 自体など、すべてをクリーンな Windows マシンに自動インストールします。インストーラーは 1 回要求すれば、残りは処理します。
⚠️ この順序どおりに取り付けてください。ほとんどすべてのインストールの問題は、ステップ 2 (管理者として実行) をスキップしたことに起因します。

インストーラーが再起動を要求した場合は、再起動し、右クリックして同じ .exe を再度実行し、[管理者として実行] を選択して終了します。
インストールには 5 ～ 15 分程度かかります。ダウンロード中に進行状況バーが数分間静止したままになる場合がありますが、これは正常であり、フリーズではありません。 「完了」ボタンとともに「インストールが完了しました」と表示された場合にのみ完了します。それまではウィンドウを開いたままにしておきます。
Kivun Terminal デスクトップ ショートカットを起動し、フォルダーを選択します (ツリーを参照するか、Windows パスを貼り付けます)。または、ファイル エクスプローラーで任意のフォルダーを右クリック → Kivun Terminal で開く を選択します。
WSL2がありません。ウィザードに「WSL がインストールされていません」と表示された場合は、ターミナル (管理者) を開き、 wsl --install を実行し、再起動してインストーラーを再実行します。これはマシンごとに 1 回だけ実行します。
SmartScreen 警告 (「Windows が PC を保護しました」): [詳細情報] → [とにかく実行] をクリックします。インストーラーは認証された発行元によってコード署名されていますが、真新しい署名は時間の経過とともに Microsoft の評判シグナルを構築するため、警告はしばらく表示され、実際のダウンロードが蓄積されるにつれて消えていく可能性があります。
Windows 11 のスマート アプリ コントロール (より難しいブロック - 「スマート アプリ コントロールは、OK ボタンのみで安全でない可能性のあるアプリをブロックしました」): SAC は非常に厳格であり、評判が得られるまで、新しく署名されたアプリをブロックする可能性があります。 [スタート] を開き、[スマート アプリ コントロール] を検索して、 [オフ] に設定します。 Windows を再インストールしないと SAC を再度有効にすることはできないため、この方法で他のアプリを実行することに慣れている場合にのみ SAC をオフのままにしてください。

What's included out of the box
🆕 Named profiles (v1.4.0+) - save folder + model + flags + startup slash-commands + environment variables per project. The chip row at the top of the picker lets you switch between profiles in one click; the active profile is highlighted blue. Per-profile env vars ( ANTHROPIC_API_KEY , DEBUG , custom MCP_* , …) are propagated through WSLENV on Windows / export on Linux so they reach the Claude Code session. Values are masked in the resolved-command preview by default for screenshot safety; click 👁 show values to reveal.
Folder picker dialog on the desktop shortcut (screenshot above) - browse the folder tree or type/paste a Windows path, plus inline radio-button model selection (Opus / Sonnet / Haiku), one-click flag chips (Respond in Hebrew, High effort, Auto-accept file edits, Read-only, etc.), and a textarea for startup slash commands like /voicemode:converse .
Right-click "Open with Kivun Terminal" on any folder in File Explorer - launches straight into that folder, skipping the picker.
Live two-line statusline at the bottom of every Claude Code session - model, context %, total tokens, session duration, and 5-hour / 7-day usage with countdown to reset.
Choose your terminal background color for Konsole, right in the folder picker's Advanced options (or via TERMINAL_COLOR= in the config). Light-blue Kivun ( #C8E6FF ) on by default; switch to dark , black , white , default (your emulator's own theme), or any custom hex like #1e1e2e . Text color is picked automatically for readability. Apply now shows a color change in a new tab (Ctrl+Shift+T) right away; otherwise it applies on your next launch.
Cap WSL's memory from the folder picker's Advanced options — WSL2 runs a small Linux VM that can hold a lot of RAM. Set a limit (saved to your .wslconfig ); it takes effect after WSL next restarts.
BiDi wrapper that fixes Hebrew/Arabic/Persian rendering bugs in Claude Code's TUI (see BiDi Wrapper below for the seven specific fixes).
Auto-installs everything - WSL2 + Ubuntu + Konsole + Node.js + Claude Code itself, on a clean Windows machine. The installer asks once and handles the rest.
⚠️ Install in this exact order. Almost every install problem comes from skipping step 2 (Run as administrator).
Download Kivun_Terminal_Setup.exe from the latest release.
Right-click the file → Run as administrator . Do not just double-click it. This lets the installer set up WSL in one go - the most common failure ("WSL install not started") is simply a missing admin step.
If a black window appears asking to create a Ubuntu user : type a username (lowercase, no spaces), press Enter, then type a password and press Enter, twice. The password stays invisible while you type - that is normal, just keep typing.
If the installer asks you to reboot , reboot, then run the same .exe again with right-click → Run as administrator to finish.
Installing takes about 5–15 minutes. The progress bar may sit still for several minutes during the download, that's normal, not a freeze. It's done only when it shows "Installation Complete" with a Finish button, leave the window open until then.
Launch the Kivun Terminal desktop shortcut → pick a folder (browse the tree or paste a Windows path), or right-click any folder in File Explorer → Open with Kivun Terminal .
WSL2 missing. If the wizard says "WSL is not installed" , open Terminal (Admin) , run wsl --install , reboot, and re-run the installer. You only do this once per machine.
SmartScreen warning ( "Windows protected your PC" ): click More info → Run anyway . The installer is code-signed by its verified publisher, but a brand-new signature still builds Microsoft's reputation signal over time, so the warning can appear for a while and fades as real downloads accumulate.
Smart App Control on Windows 11 (the harder block - "Smart App Control blocked an app that may be unsafe" with only an Ok button): SAC is very strict and may still block a newly signed app until it earns reputation. Open Start → search Smart App Control → set it to Off . SAC cannot be re-enabled without reinstalling Windows, so leave it off only if you're comfortable running other apps this way.
Still stuck? Send a 1-click report. Download kivun-diagnostics.cmd from the latest release (or open "Kivun Diagnostics" from the Start menu if it installed) and double-click it. It saves Kivun-Report.txt to your Desktop - email it to noambbb@gmail.com . No admin, nothing sent automatically.

Supports apt (Debian/Ubuntu), dnf (Fedora/RHEL), pacman (Arch/Manjaro), zypper (openSUSE). Installs Konsole, Node.js, Git, Claude Code, the BiDi wrapper, and right-click integrations for Nautilus + Dolphin.
Not supported as of v1.2.4. No native macOS terminal renders mixed Hebrew + English correctly today (Apple Terminal lacks a BiDi engine, iTerm2 3.6.x mirrors Hebrew, WezTerm's bidi_enabled is half-broken in mixed scripts). For Hebrew work on Mac, use a Windows or Linux machine. Full context, evidence, and uninstall instructions in mac/README.md . Existing v1.2.x Mac users can still download the deprecated .pkg from the v1.2.3 release for rollback purposes.
First run on Windows or Linux requires a Claude Pro/Max subscription or an Anthropic API key .
First launch is slow: the very first time you open Kivun, the window can take about
10–15 seconds to appear (it sets up the Hebrew renderer and starts Claude). That's
normal — please wait a few seconds before assuming anything's wrong.
Window is blank or only in the taskbar? Open the Start menu → "Repair Kivun
Display" (one click). It restarts the part of Windows that draws Linux windows, then
open Kivun again. No commands to type — the installer also does this for you at the end of
setup, so you usually never need it.
If that didn't help, or you see an error, please send us a small report. It tells us what
went wrong on your computer so we can fix it fast. This helps far more than describing
what you saw, and it is the quickest way to get it solved.
If an error appeared, the report opens by itself — you don't have to do anything.
Otherwise, click Start (the Windows button), type Kivun Diagnostics , and press
Enter .
A file called Kivun-Report.txt is saved to your Desktop and opens on screen.
A folder also opens with that file already highlighted — so you don't have to hunt
for it.
Drag the highlighted file into either:
an email to noambbb@gmail.com , or
a new post at https://github.com/noambrand/kivun-terminal-wsl/issues
Nothing is sent on its own — you're in control. That's it; we'll take it from there.
