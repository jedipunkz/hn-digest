macOS および Linux 上で最新バージョンの Claude Code を実行しているユーザーは、セッションで相互にメッセージを送信して、結果を共有したり、質問したり、作業を調整したりできるようになりました。詳細は次のとおりです。
Claude Code がクロスセッションメッセージングを取得
本日、Anthropic は、複数のクロード コード セッションを同時に実行する傾向があるユーザーにとって非常に歓迎される機能を発表しました。
Claude Code v2.1.224 以降、異なるセッションが更新情報やその他の関連情報を互いにメッセージ送信できるようになりました。これは、ユーザーが同じプロジェクトの異なる部分で複数のセッションを作業している場合に特に便利です。
Claude Code の新機能: セッションが相互にメッセージを送信できるようになりました。
別のセッションで自分自身を再度説明する代わりに、クロードに説明するように指示できます。概要 (履歴やファイルではない) が送信され、他のセッションがタスクの途中でそれを取得します。 pic.twitter.com/PtNsfXeQXP
新機能に関する Anthropic のドキュメントから:
クロスセッション メッセージングを使用すると、クロードはクロード コード セッションの 1 つから別のセッションにメッセージを配信できます。あるセッションでの変更により、別のセッションの構築が中断されると、クロードはユーザーが気づく前にそのセッションに警告することができます。あるセッションで他のセッションがブロックされている質問が解決されると、クロードは答えを送信できます。
Anthropic 氏によると、この新機能の最適な使用例には、調査結果の引き継ぎ、並列ワークツリーの調整、長時間実行される作業からのステータスの取得、マシン間での応答などが含まれます。
ユーザーはメッセージの作成自体について心配する必要はない、と同社は付け加えた。むしろ、プロンプトには t のみを含めることができます。

彼が伝えたい内容を伝えると、クロードが実際のメッセージを書きます。
重要なのは、クロスセッション メッセージングは​​、権限リクエストの承認や構成の変更には機能しないことです。 /compact などのコマンドは、実際のコマンドではなくプレーン テキストとして受信され、メッセージに対する操作に許可が必要な場合でも、受信セッションではユーザーに承認を求めるメッセージが表示されます。

Claude Code now lets sessions talk to each other on macOS

Users running the latest version of Claude Code on macOS and Linux can now have their sessions message each other to share findings, ask questions, and coordinate work. Here are the details.
Claude Code gets cross-session messaging
Earlier today, Anthropic announced a feature that will likely be very welcome to users who tend to run multiple Claude Code sessions at once.
As of Claude Code v2.1.224, different sessions can message each other with updates and other relevant information, which can be especially useful when the user has multiple sessions working on different parts of the same project.
New in Claude Code: your sessions can now message each other.
Instead of having to re-explain yourself in another session, you can now tell Claude to do it. It sends a summary (not your history or files), and the other session picks it up mid-task. pic.twitter.com/PtNsfXeQXP
From Anthropic’s documentation of the new feature:
Cross-session messaging lets Claude deliver a message from one of your Claude Code sessions to another. When a change in one session breaks what another is building on, Claude can warn that session before you notice. When one session settles a question another is blocked on, Claude can send the answer across.
Anthropic says the best use cases for the new feature include handing over a finding, coordinating parallel worktrees, getting status from long-running work, and replying across machines.
The company adds that users don’t need to worry about composing the message itself. Rather, the prompt can include only the content they want to get across, and Claude will write the actual message.
Importantly, cross-session messaging doesn’t work for approving permission requests or changing configurations. Commands such as /compact arrive as plain text rather than an actual command, and if acting on the message requires a permission, the receiving session will still prompt the user for approval.
