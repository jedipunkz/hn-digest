## Translation

タイトル: Gemini API により後払い請求が廃止される
HN テキスト: メール受信: Google AI Studio と Gemini API に対する今後の請求変更についてお知らせします。開発者は、2026 年 9 月 14 日までに Gemini API の請求を後払いから前払いに切り替える必要があります。これは、開発者が API の使用量とコストをより詳細に制御できるようにプラットフォームを改善する継続的な取り組みの一環です。この変更は、AI Studio での Gemini API の使用にのみ適用されます。アカウント上の他のすべての GCP サービスは後払いのままになります。
知っておくべきこと 主な変更点:
2026 年 9 月 14 日以降、Gemini API の有料機能を使用するには、Google AI Studio プロジェクトに関連付けられた料金プランを前払いに変更する必要があります。前払い料金プランの詳細については、こちらをご覧ください。潜在的な影響:
2026 年 9 月 14 日までに前払いに移行してクレジットを購入しない場合、サービスは中断されます。
必要な操作 必要なアクション: Gemini API の有料機能を使用している、または使用する予定がある場合:
前払いに切り替える: AI Studio の請求ページで前払いに移行し、クレジットを購入して、有料の Gemini API 機能を引き続き使用します。
推奨事項:
サービスの中断を避けるために、2026 年 9 月 14 日の移行日より前に切り替えてください。
自動リロードを設定して、前払い残高を自動的に補充し、今後のサービスの中断を防ぎます
AI Studio の請求ページで現在の請求プランを表示し、支払い方法を管理し、前払いに切り替えます。
現在 Gemini API の有料機能を使用していない場合は、何もする必要はありません。

## Original Extract

Mail received: We are writing to inform you of an upcoming billing change to Google AI Studio and the Gemini API. We require developers to switch your Gemini API billing from Postpay to Prepay by September 14, 2026. This is part of our ongoing effort to improve our platform to give developers more control over API consumption and costs. This change applies exclusively to your Gemini API usage in AI Studio. All other GCP services on your account will remain on Postpay.
What you need to know Key changes:
Starting September 14, 2026, to use paid features in the Gemini API you will be required to change the billing plan associated with your Google AI Studio projects to Prepay. Learn more about the Prepay billing plan here. Potential impact:
If you do not transition to Prepay and purchase credits before September 14, 2026, your service will be interrupted.
What you need to do Action required: If you use, or plan to use, paid features in the Gemini API:
Switch to Prepay: Transition to Prepay on the AI Studio billing page and purchase credits to continue using paid Gemini API features
Recommendations:
Switch before the September 14, 2026 migration date to avoid service interruptions
Configure auto-reload to automatically top up your Prepay balance and prevent future service interruptions
View your current billing plan, manage payment methods, and switch to Prepay on the AI Studio billing page
No action is required if you do not currently use paid features in the Gemini API
