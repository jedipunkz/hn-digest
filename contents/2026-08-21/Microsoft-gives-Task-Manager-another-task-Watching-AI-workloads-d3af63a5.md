タスク マネージャーは、Dave Plummer が 1990 年代に「非常に Unixy の衝動」と呼んだものに触発されて開発したアプリケーションから大きく進化しました。今週、Microsoft は、AI ワークロードのより深い可視性という最新の機能を強調しました。
「以前は、[プロセス] タブには、ニューラル プロセッシング ユニット (NPU) またはグラフィックス プロセッシング ユニット (GPU) ニューラル エンジンのプロセスごとのアクティビティが表示されませんでした」と Microsoft は説明しました。
現在は、少なくともサポートされている新しいデバイスでは機能します。 [プロセス] タブには CPU および GPU のアクティビティとともに NPU 使用量が表示され、[パフォーマンス] タブには全体的な使用率が表示されます。

とはいえ、どのプロセスがどのハードウェアを使用しているかを知ることは、特にバッテリ駆動のラップトップでパフォーマンスと電力消費の問題を診断するのに役立ちます。
Microsoft は、監視できる指標について熱心に指摘していました。 「Windows デバイス上で AI ワークロードがより一般的になるにつれて、NPU と GPU ニューラル エンジンの使用状況を可視化することで、より適切な情報に基づいた意思決定が可能になります」と同社は述べています。 「最新のタスク マネージャーの改善により、CPU と並行して AI 処理アクティビティを監視できるようになりました。

Per-process NPU metrics arrive as one more venerable Windows utility risks feature bloat
Once upon a time, Windows Task Manager was a stone-cold killer. Optimized to within an inch of its life, it struck fear into errant processes. These days, Microsoft also wants it monitoring AI workloads.
Task Manager has come a long way from the application Dave Plummer developed in the 1990s , inspired by what he called a "very Unixy impulse." This week, Microsoft highlighted its latest addition: deeper visibility into AI workloads.
"Previously, the Processes tab didn't show per-process activity for the neural processing unit (NPU) or graphics processing unit (GPU) neural engine," Microsoft explained .
Now it does, at least on supported newer devices. The Processes tab can show NPU use alongside CPU and GPU activity, while the Performance tab displays overall utilization.
It is handy, although Task Manager appears to be spending ever more time monitoring tasks rather than managing them.
That said, knowing which processes are using which hardware can help diagnose performance and power consumption problems, particularly on a battery-powered laptop.
Microsoft was keen to point out the metrics that can be monitored. "As AI workloads become more common on Windows devices, visibility into NPU and GPU neural engine utilization can help you make better-informed decisions," the company said. "With the latest Task Manager improvements, you can monitor AI processing activity alongside CPU, memory, storage, and networking data from a familiar interface."

Whether users want that degree of telemetry in Task Manager is another question. Finding a memory leak or killing a CPU hog fits its traditional remit; extended system analysis might be better left to Performance Monitor.
Notepad was once a lightweight application focused on doing one thing well. It has since accumulated tweaks and enhancements before enduring the indignity of AI-powered text editing services. The same fate could await Task Manager.
The additional metrics will undoubtedly be useful to developers. Whether they represent helpful visibility or another step toward feature bloat depends on whether Microsoft can add them without compromising the speed and simplicity that made Task Manager indispensable. ®
