AI is getting pretty good at writing code. Not all of it, obviously, but enough that I keep wondering what this does to the job of a software engineer. If writing the code is no longer the hard part, what is? Understanding the problem? System design? Knowing the product and users? Making good decisions about what to build? What do you think will make someone a really good software engineer in the next few years?
