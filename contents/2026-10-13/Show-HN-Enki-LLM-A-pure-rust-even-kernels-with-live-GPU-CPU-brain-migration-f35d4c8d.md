Enki LLM: Llama-3.2 1B in Pure Rust (Zero CUDA Dependencies)
A pure Rust Transformer inference engine (~2,000 LOC) running Llama-3.2 1B at ~40 tok/s on an Nvidia Tesla T4 GPU, with live brain migration between GPU VRAM and CPU RAM mid generation.
Live Demo: Brain Migration (GPU to CPU)
The session begins generating Python code on the GPU (white text), switches live via /dual mode (320ms migration), and continues streaming the explanation by alternating tokens between the GPU (white) and Host CPU cores (bold red) while btop tracks the CPU spikes.
High-Performance Pure-Rust Inference: Runs unquantized F16 weights with FP32 accumulators at ~40 tokens/sec on Nvidia Tesla T4.
Live Brain Migration (GPU/CPU): Seamlessly hot-swaps active execution and mirrors KV-cache between GPU VRAM and CPU RAM mid-sentence without losing context.
Cross-Silicon Portability: The exact same binary runs on discrete GPUs (Nvidia), integrated graphics (Intel UHD), and multi-core CPUs without modifying a single line of code.
Minimalist Implementation (~2,000 LOC): Everything, Safetensors parser, Tokenizer, Split-K GEMV, RoPE, RMSNorm, SwiGLU, and generation sampling—is built from scratch in pure Rust.
Traditional Rust GPU tools either wrap CUDA/C++ or transpile syntax into WGSL. This project is built directly on top of the Enki runtime:
Idiomatic Rust Kernels: Compute passes are authored as regular Rust functions marked with the #[nam] attribute.
Direct LLVM-to-SPIR-V JIT: Enki's compiler ( Parsu ) ingests the standard LLVM bitcode generated by rustc ( --emit=llvm-bc ) and compiles it directly into SPIR-V compute shaders at runtime.
Hardware Dispatch via Vulkan 1.3: Execution runs natively on the hardware via Vulkan 1.3 using 64-bit Buffer Device Addresses (BDA) for pointer-like memory ergonomics on the GPU.
Host Fallback: When migrated to CPU, the same kernels execute natively in parallel across all CPU cores using Rayon.

During generation, you can control the engine in real time:
/gpu — Migrate active execution and KV-cache to GPU Silicon.
/cpu — Migrate active execution to Host CPU cores (Rayon).
/dual — Ping-pong mode (alternates tokens between GPU and CPU live).
/reset — Clear conversation memory and reset KV-cache.
Requirements: Vulkan 1.3 drivers and a standard Rust toolchain.
