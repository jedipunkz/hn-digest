100% Open & Community Maintained: Actively monitored for active repositories, preprint tools, and reproducible computational workflows.

🔍 Literature Discovery & Semantic Search
Tools that replace brittle keyword queries with semantic vector search and claim extraction.
Consensus — AI search engine extracting empirical consensus and findings directly from peer-reviewed scientific papers.
Elicit — AI research assistant using language models to automate literature reviews, synthesize summaries, and extract structured data columns from PDFs.
Semantic Scholar — Free, AI-backed academic search engine providing citation velocity, influential citations, and automatic TLDRs.
Scite.ai — Smart citation index indicating whether citations support, mention, or contrast with target study findings.
Undermind — Deep exploration agent executing multi-step search loops to uncover obscure and hard-to-find papers.
🕸 Citation Graphs & Prior Art Mapping
Interactive visualization engines to explore academic ancestry, co-citations, and research trends.
Connected Papers — Visual graph generator showing similarity and co-citation clusters for any given paper.
Litmaps — Generates citation timelines and maps to track related literature and receive alerts for new publications.
ResearchRabbit — Spotify-like discovery canvas for papers, authors, and institutional networks.
Inciteful — Free, open-source network analysis tool exploring academic graphs and institutional clusters.
📖 Paper Reading & Deep Synthesis
Accelerate comprehension of mathematical formulations, dense methodology sections, and supplemental proofs.
NotebookLM — Grounded research notebook designed to synthesize multi-source PDFs, extract cross-document citations, and generate structured audio discussions.
SciSpace — Interactive paper reader providing highlighted explanations for math formulas, complex tables, and domain jargon.
ChatPDF — Fast, zero-friction conversational interface for querying single research PDFs.
Explainpaper — Highlight confusing scientific prose to generate instant plain-English explanations.
✍️ Writing, LaTeX & Academic Grammar
Tools crafted specifically for LaTeX workflows, BibTeX sanitization, and scholarly English editing.
LaTeX-OCR (pix2tex) — Open-source deep learning tool converting images and screen clippings of math equations into clean LaTeX code.
Paperpal — Academic editing engine trained on millions of peer-reviewed articles to fix syntax, phrasing, and academic tone.
Writefull — AI proofreader and sentence palette tailored for research manuscripts and Overleaf integration.
Mathpix Snip — Industry standard for extracting LaTeX math, markdown, tables, and chemical structures from images and PDFs.
Overleaf Toolkit — Cloud LaTeX editor supporting Git bridges and automated compilation checks.
Ensure absolute reproducibility of model runs, hyperparameter sweeps, and compute logs.
Weights & Biases (W&B) — Standard platform for tracking ML experiments, dataset versioning, model registries, and system hardware metrics.
MLflow — Open-source platform managing the full ML lifecycle including experimentation, reproducibility, and deployment.
ClearML — Open-source suite for experiment management, orchestration, data versioning, and remote GPU scheduling.
DVC (Data Version Control) — Git-native data version control and pipeline management for machine learning datasets.
💻 Paper-to-Code & Reproducibility
Bridging the gap between theoretical algorithms and working implementations.
Papers with Code — Open platform linking machine learning papers directly to code repositories, datasets, and SOTA leaderboards.
Hugging Face Papers — Daily trending machine learning papers curated by the community with integrated model weights and demo Spaces.
Zenodo — CERN-backed open repository generating permanent DOIs for research datasets, codebases, and artifacts.
Code Ocean — Cloud-based computational reproducibility platform executing self-contained compute capsules.
🎨 Scientific Diagrams & Data Visualization
Create publication-ready figures, graphical abstracts, and architectural workflows.
BioRender — Web platform for building standardized scientific figures, biological pathways, and medical illustrations.
BioIcons — Free, open-source library of vector scientific illustrations (SVG) under permissive open licenses.
Mermaid.js — Markdown-inspired diagramming tool rendering flowcharts, state diagrams, and sequences directly in code repositories.
Excalidraw — Virtual collaborative whiteboard for sketching intuitive system architectures and paper overview figures.
Agents that autonomously search the web, formulate hypotheses, and draft literature reviews.
STORM (Stanford) — LLM system executing internet research to generate Wikipedia-style comprehensive reports with citations.
Auto-Researcher — Autonomous agent designed for comprehensive online research on any topic.
ChemCrow — Chemistry-focused agent integrating computational chemistry tools and synthesis planning.
