EasyRunCraft is an online suite of 13 office and creative editors for documents, spreadsheets, presentations, PDFs, photos, design, video, audio, and 2D CAD. You can open a file or start a new project in your browser, edit it manually, and save the result. Built-in AI assistance and MCP access are also available for supported tasks.
For office work, use WordCraft for documents, GridCraft for spreadsheets, DeckCraft for presentations, and PdfCraft for PDFs. Image and design tools include PhotoCraft , LightCraft , VectorCraft , FigCraft , and DesignCraft .
FilmCraft handles video editing, EffectCraft handles motion graphics, SoundCraft handles audio editing and mixing, and CADCraft handles 2D CAD drawings.
EasyRunCraft is for students, independent creators, designers, developers, and small teams who need browser-based editing tools. Typical tasks include revising a report, updating a budget spreadsheet, preparing slides, editing a photo, or trimming a video. Choose the editor for your task and check its supported file formats before starting.
Yes. Choose an editor from the tool list, then open a supported file from your device or create a new project. Manual editing runs in your browser and requires neither a software installation nor an account. Sign in when you want to use shared AI credits or create a token for MCP access.
Open an editor’s AI panel and describe the change you want. For example, ask WordCraft to revise a paragraph, GridCraft to update a cell range, or DeckCraft to change slide text. Supported commands apply changes to the file open in the editor, where you can review the result and use native undo. Available AI features and editing actions vary by tool.
Yes. EasyRunCraft provides an MCP endpoint for Codex, Claude Code, and other compatible AI clients. Follow the MCP setup guide to sign in, create a dedicated MCP token and connect your client. Your agent can use the available tools to inspect or modify supported files and return a download link for the result.
Each successful MCP atomic operation costs 1 credit, including file inspection, editing, audio conversion, video export and animation rendering. One complete task may need several atomic operations. Credits are reserved before execution and charged only on success. Failed or cancelled tasks release the reservation. Uploads, quotes, capability checks, status polling and downloads have no separate charge. MCP credits pay for file processing, not AI model tokens. Your external agent’s model usage is billed by its provider.
You can manually create, edit and export files in all 13 browser editors for free, without an account. New users receive free credits on their first sign-in to try the built-in AI features. AI usage draws from your shared credit balance.
EasyRunCraft’s editors are based on the open-source Crafting Apps projects by ArtCraft, available on GitHub . EasyRunCraft adds browser integrations, built-in AI assistance, a shared account, and MCP access for supported file tasks. The About page lists the original projects, contributor credits, license notices, and official desktop downloads.
Manual file editing runs in your browser. When you use AI, the context or attachments needed for your request are sent to the selected provider, through our account service. MCP tasks upload files to our servers for processing. Your EasyRunCraft account is not cloud file storage; see the privacy policy for details about data handling.
Use the editor’s Save or Export command to download your work to your device. Available formats depend on the editor: for example, GridCraft works with XLSX spreadsheets, DeckCraft with PPTX presentations, and CADCraft with DXF drawings. For MCP tasks, download the updated file from the link your agent returns. Save important changes before closing the editor.
