HN text: Hi HN! Dez is a free open source way to interact with AIs across providers in a full-featured text editor. ## Original Extract

Plain text AI multimedia studio. Contribute to taoeffect/dez development by creating an account on GitHub.

Hi HN! Dez is a free open source way to interact with AIs across providers in a full-featured text editor. I really loved Zed's text threads feature, and after they removed it got inspired to revive it in this app. In this latest release, Dez acts as a sandboxed agent with multimedia focused tools. It can invoke other models to generate assets and call its bundled ffmpeg to edit them. Dez won't harm your computer, it has no way of doing so, and the ffmpeg command is sandboxed with Seatbelt on macOS and Landlock on linux. It's also built with privacy in mind, so it's designed not to send absolute file paths to providers that might reveal things like usernames, folder names, etc. Give it a try and let me know what you think!
